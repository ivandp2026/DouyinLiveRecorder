# 抖音弹幕热点分析

本功能将弹幕事件和 FFmpeg 录制使用同一条时间轴，录制结束后在视频旁生成：

- `*.danmaku.csv`：每秒评论数、独立发言人数、礼物数、点赞数；
- `*.danmaku.txt`：去重后的弹幕文本，每行包含视频时间点和内容；
- `*.highlights.json`：建议切片的开始、结束、峰值秒和评论总量。

## 配置

编辑 `config/config.ini` 的 `[弹幕分析]`：

```ini
是否开启抖音弹幕分析(是/否) = 是
弹幕采集命令 =
内置弹幕组件路径 =
内置弹幕组件端口 = 1088
重复弹幕过滤时间(秒) = 60
```

Windows 默认启动 `vendor/douyinlive/douyinLive.exe`，连接实际抖音互动消息并自动把
当前直播间 Cookie 传给它。该组件使用本地签名，不需要安装 Go 或申请在线 API Key。
网页直播间链接和 `v.douyin.com` 分享链接都会在录制阶段解析为实际房间标识。

内置组件来自 `jwwsjlm/douyinLive v2.0.24`，按其 MIT 许可证随包分发。若 1088
端口已被其他程序使用，可修改端口配置。

下面的“外部采集器”接口仅用于高级用户替换内置组件；普通用户不用配置。

## 外部采集器（可选）

当 `弹幕采集命令` 不为空时，程序改为启动该命令。它通过环境变量读取参数：

- `DOUYIN_ROOM_URL`：当前直播间链接；
- `DOUYIN_COOKIE`：`config.ini` 中配置的抖音 Cookie。

采集器向标准输出逐行写 UTF-8 JSON。支持以下事件：

```json
{"type":"chat","user_id":"123","content":"好精彩"}
{"type":"gift","user_id":"123","count":2}
{"type":"like","user_id":"456","count":10}
```

`type` 也可使用 `comment`、`WebcastChatMessage`、`WebcastGiftMessage`、
`WebcastLikeMessage`；字段名也可使用 `method`。非 JSON 日志行会被忽略。

抖音互动消息协议、签名和 Protobuf 结构会变化，因此采集器与录制程序保持隔离。
替换采集器不会改变 CSV/JSON 格式，也不会影响视频录制。

## 热点规则

默认比较最近 10 秒的平均评论数与此前 60 秒的基线。最近均值同时达到：

1. 每秒至少 5 条评论；
2. 基线的 2.5 倍；

才会判定为热点。输出区间默认向前扩展 15 秒、向后扩展 25 秒，间隔不超过
10 秒的热点自动合并。所有数值都可在 `[弹幕分析]` 中调整。

完全相同的弹幕文本在默认 60 秒内只保存和统计一次，用于过滤福袋口令等集中
刷屏；空白差异会先被规范化。超过过滤时间后再次出现会重新保留。设置为 `0`
可关闭重复过滤。
